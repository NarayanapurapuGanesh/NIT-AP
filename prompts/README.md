# FacultyIQ Prompt Engineering Repository

Contains system prompts, agent instructions, and context templates for Ollama and LangGraph agent reasoning engines.

## 📝 Standards

- Every prompt template must specify expected inputs, output schemas, and fallback behaviors.
- Prompts follow the guidelines outlined in `docs/architecture/31_PROMPT_ENGINEERING_CONTEXT_ENGINEERING_AND_AGENT_REASONING_STANDARD.md`.
