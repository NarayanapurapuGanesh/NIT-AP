# FacultyIQ AI Services Foundation

This directory houses future Python-based microservices, LangGraph agent workflows, and specialized AI processing pipelines.

## 🧠 Responsibilities

- **LangGraph Workflows**: Orchestrating multi-step research verification and applicant dossier evaluation.
- **Ollama Integration**: Local offline LLM inference connectors.
- **PyTorch/Python Tools**: Deep publication citation parsing and video interview synthesis tools.

## 🔌 Extension Points

- New agent workflows are created as isolated subpackages within `ai-services/agents/`.
- Model evaluators and prompt testing hooks belong in `ai-services/evaluators/`.
